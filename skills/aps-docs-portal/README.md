# APS Documentation Portal Skill

Navigate the [APS documentation portal](https://aps.autodesk.com/developer/documentation) — find the right API docs, decode glossary terms, crawl table-of-contents JSON trees, extract content from static HTML pages, and convert CDN URLs to clickable portal links. Covers ACC, BIM 360, Model Derivative, Data Management, Viewer, Design Automation, Authentication, Webhooks, and all related APS APIs.

## Requirements

- `curl`, `jq`, and `htmlq`

## Installation

Recommended (project-level):

```bash
npx skills add autodesk-platform-services/skills --project --skill aps-docs-portal
```
