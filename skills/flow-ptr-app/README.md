# Flow Production Tracking App Skill

Guide for developing Flow Production Tracking (FPTR) / ShotGrid Toolkit (sgtk) apps following a spec-driven lifecycle — capture intent, write and validate a spec, plan, implement, verify, release, and maintain.

## Installation

Recommended (project-level):

```bash
npx skills add autodesk-platform-services/skills --project --skill flow-ptr-app
```
